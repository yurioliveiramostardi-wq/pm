# APP_SCHOLAR
O APP_SCHOLAR foi desenvolvido para organizar uma escola em forma de aplicativo, nesse aplicativo podemos usar telas para ver alunos, professores, coordenadores, turmas, cursos, responsaveis, matriculas, disciplinas e avaliações todas as telas podem ser alteradas, como colocando alunos novos, professores novos, turmas e cursos.

FUNCIONALIDADES:
CADASTRO DE ALUNOS, CADASTRO DE PROFESSORES, CADASTRO DE COORDENADORES, CADASTRO DE RESPONSAVEIS E CADASTRO DE CURSO
CONSULTA DE NOTA DE TODOS OS ALUNOS E CONSULTA DE PROFESSORES COM SEUS DIPLOMAS
ATUALIZAÇÕES DE INFORMAÇÕES DE ALUNOS E PROFESSORES EM TEMPO REAL
EXCLUSAO DE NOTA E CURSO 
NAVEGAÇÃO EM TODAS AS TELAS SUAVEMENTE 

TECNOLOGIAS USADAS:
CSS
JAVA SCRIPT
HTML

ESTRUTURA DO PROJETO:
CADA TELA DO APP FOI FEITA EM APENAS UM ARQUIVO, PARA EU ME ORGANIZAR MAIS FACIL E PARA NAO TER QUE USAR TANTAS PASTAS, E NA PARTE DA API USEI UMA UNICA PASTA NO HTDOCS PARA FAZER A API AONDE LIGA CADA TELA ( ALUNO, PROFESSORES, COORDENADORES E ETC...)
